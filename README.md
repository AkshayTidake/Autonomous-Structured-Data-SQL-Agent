# Autonomous Relational SQL Analytics Engine 📊🗄️

An enterprise-grade, deterministic analytics pipeline that translates natural language business questions into safe, executable, and highly optimized SQLite queries over complex multi-table relational databases.

Rather than relying on generic black-box agent factories that frequently throw API tool-calling faults, this architecture decouples operations into a custom **Sequential LangChain Expression Language (LCEL) Chain Framework**. It features structural database schema reflection, runtime text cleanup, and an analytical dashboard detailing intermediate query thoughts alongside final parsed data summaries.

---

## ⚡ Key Architecture & Features
* **Decoupled Chain Pipeline:** Implements a strict dual-stage pipeline (Text-to-SQL Translation + Data-to-Text Synthesis) ensuring precise query generation and zero conversational hallucinations.
* **Structural Schema Reflection:** Dynamically extracts database metadata configurations, boundaries, and constraint identifiers at run-time, passing strict localized constraints to the high-reasoning engine.
* **Transparent Execution Trace:** Renders an intermediate debugger expander in the UI, exposing the exact autogenerated raw SQL code and raw database transaction matrices directly to the user.
* **Fail-Safe Sanitization Blocks:** Built custom regex-adjacent cleaning strings to catch and strip out arbitrary markdown tags (e.g., ` ```sql ` blocks), preventing query runtime syntax breaks.
* **Relational Mock Ecosystem:** Configured a multi-table business simulation setup spanning independent relational schemas (`customers`, `products`, `orders`) mapped through explicit foreign-key bindings.

---

## 🛠️ Tech Stack & Ecosystem
* **Orchestration Layer:** LangChain Core / LangChain Expression Language (LCEL v1.0+)
* **Database Driver:** SQLite3 Core Engine (Local Relational Instance)
* **Core LLM Engine:** Groq Cloud SDK High-Reasoning Endpoint (`openai/gpt-oss-120b` cluster)
* **Frontend Web Framework:** Streamlit Dashboard Utility
* **Environment Controller:** Python-Dotenv Variables Management
